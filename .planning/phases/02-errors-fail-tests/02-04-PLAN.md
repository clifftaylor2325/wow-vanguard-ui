How to mark a deliberate error (D-01; the API from plan 02-01):
- Import `expectErrors` and `AURA_FALLBACK` from `./helpers.mjs`. Inside the case, call `expectErrors(...)` with one matcher per distinct entry the case causes on purpose.
- A matcher is the whole entry text as a string, or, only where a line number or a generated counter varies, a RegExp anchored with `^` and `$` that varies only in digit runs (`\d+`) and escapes every other symbol. `expectErrors` enforces this (plan 02-01) and throws a TypeError naming D-01 for anything broader: an unanchored, empty or wildcard pattern, a character class, a group, an alternation, `\w`/`\s`, a `g`/`m`/`y` flag, or an empty string.
- Every matcher must match an entry ("expected but never seen" otherwise). Cleared entries are still judged.

D-04 stop rule: an entry that is not the point of its case is unexpected. Fix it at its cause; never mark it. Record every such root cause with its texts and cases in the SUMMARY under `## D-04 tally`. STOP and return `## CHECKPOINT REACHED` with the list, before committing more, if:
- this plan meets more than 3 such root causes; or
- one fix would change more than about 20 lines of addon code, touch a second addon file, or change what a player sees.
The user decides. Do not choose a fix or a marker for them, and commit nothing further until they answer.
